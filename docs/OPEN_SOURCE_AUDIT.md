# 开源审查记录

审查日期：2026-07-25

## 审查范围

- Git 跟踪文件和忽略规则。
- 高置信度密钥特征。
- GitHub Actions 测试状态。
- Apache-2.0 许可证、NOTICE、贡献和安全说明。
- 内置入库单、出库单的内容和 OOXML 包结构。
- 公开仓库的 README、Issue 和 Pull Request 入口。

## 已确认

- 未发现高置信度 API 密钥、访问令牌或私钥。
- `.env`、数据库、工作区、票据、导出文件、OCR 模型、`build/` 和 `dist/`
  均在忽略规则中。
- 当前 Git 跟踪内容不包含用户工作区或真实上传票据。
- 两份内置模板没有宏、隐藏工作表、批注、嵌入对象或外部关系。
- 项目保留上游 InvoiceOCR 的许可证归属和 NOTICE。
- CI 使用只读仓库权限并在 Windows Python 3.12 环境运行。

## 已处理

- 补充项目适用范围、已知限制、隐私和人工复核声明。
- 补充 Issue 表单、PR 模板、行为准则和变更记录。
- 修复 Windows 临时目录长路径与 8.3 短路径导致的 CI 测试误报。
- 在 README 中加入持续集成状态和许可证信息。

## 已知并暂时接受

- 内置 Excel 模板保留示例采购记录和原始文档属性。
- 模板不是学校官方维护版本，也不保证适用于其他单位。
- Windows 便携版未进行代码签名。
- PaddleOCR 和模型体积较大，因此不提交到 Git 仓库。
- 项目没有固定的安全响应或长期版本支持承诺。

## 后续发布前建议

- 用获得明确授权的脱敏通用模板替换当前示例内容和文档属性。
- 对每个公开便携包记录 SHA256，并保留构建提交号。
- 发布前从全新目录解压并运行离线冒烟测试。
- 对新增二进制文件重新执行密钥、个人信息和外部链接检查。

本记录是项目维护检查，不是法律、合规或财务审计意见。
